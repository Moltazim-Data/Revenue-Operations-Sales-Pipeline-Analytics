# Insight playbook

Use the generated outputs to answer business questions rather than presenting synthetic numbers as real-world findings.

1. **Pipeline coverage:** compare open pipeline value with recent booked revenue; call out that this project uses an unweighted amount.
2. **Conversion:** compare stage counts and closed-opportunity win rate. Always show denominators.
3. **Source quality:** compare both lead-source win rate and booked revenue; small sample sizes can create volatile rates.
4. **Sales effectiveness:** rank reps by booked revenue while also showing win count and deal size to avoid one-metric conclusions.
5. **Cycle time:** inspect median and distribution, not only the mean; segment by deal size or account segment.
6. **Data quality:** report duplicate IDs, missing dates, negative amounts, and inconsistent status flags before trusting KPIs.

Do not claim causality from descriptive comparisons. Label every dashboard page as using synthetic demo data.
