# Portfolio Analysis Report — Revenue Operations & Sales Pipeline

## Purpose
Assess pipeline health, stage conversion, win rate, opportunity amount, sales-cycle duration, and lead-source performance.

## Recommended report sections
1. Executive overview: total opportunities, open pipeline, win rate, won amount proxy.
2. Funnel: stage counts and conversion rates.
3. Trends: opportunity creation and closed-won amount over time.
4. Segment analysis: lead source, region, and segment.
5. Action list: pipeline gaps, data checks, and follow-up questions.

## Interpretation guardrails
CRM data is synthetic; opportunity amounts are proxies, not accounting revenue. Win rate should use only closed-won plus closed-lost opportunities. The HTML preview is not a native Power BI file.

## Suggested action
Prioritize high-value pipeline gaps and compare forecast assumptions with later outcomes.
